# Mover Lifecycle Evidence

This folder contains screenshots documenting an employee department transfer within the Enterprise IAM lab.

## Evidence Included

- Approved HR transfer request
- Department attribute update
- Job title update
- Manager update
- Organizational Unit validation
- Access review
- Active Directory modifications
- PowerShell verification
- Audit validation

## Purpose

These screenshots demonstrate the Mover lifecycle process by documenting identity updates while maintaining continuity of the employee account and enforcing least-privilege access.
