# Leaver Lifecycle Evidence

This folder contains screenshots documenting the secure offboarding of an employee from the Enterprise IAM lab.

## Evidence Included

- Approved HR termination request
- Account disable operation
- Organizational Unit transfer to Disabled Users
- Identity preservation
- Active Directory validation
- PowerShell verification
- Audit confirmation

## Purpose

These screenshots demonstrate the Leaver lifecycle process by securely disabling user access while preserving the employee identity for auditing and compliance purposes.
