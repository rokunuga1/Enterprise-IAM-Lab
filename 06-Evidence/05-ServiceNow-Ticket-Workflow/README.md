# ServiceNow Ticket Workflow Evidence

This folder contains screenshots documenting the simulated ServiceNow Identity and Access Management workflow used throughout the Enterprise IAM lab.

## Evidence Included

- HR request
- Manager approval
- ServiceNow request creation
- IAM validation
- Identity provisioning

## Purpose

These screenshots demonstrate a ServiceNow-style IAM workflow that mirrors enterprise identity operations. The workflow illustrates how Joiner, Mover, and Leaver requests are received, validated, processed, documented, and successfully completed.
